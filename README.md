# Mona Tarek Mohamed | AI Engineer Portfolio

Static portfolio site (plain HTML/CSS/JS, no build step).

## Deploy with GitHub Pages
1. Put these files in the root of the `main` branch.
2. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Site goes live at https://mona1tarek.github.io/portfolio-website/
