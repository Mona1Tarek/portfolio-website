# Mona Tarek Mohamed — Portfolio

A responsive, static portfolio built with HTML, CSS, and JavaScript. It is suitable for GitHub Pages and does not require a React build step.

## Files
- `index.html` — portfolio content and page structure
- `styles.css` — styling and responsive layouts
- `script.js` — mobile navigation, reveal effects, and footer year

## Publish to the existing GitHub Pages repository
1. Download and extract this ZIP.
2. Back up the current repository files.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root, alongside any existing files you want to keep.
4. Commit the changes and wait for GitHub Pages to redeploy.

The current portfolio repository's published page is a static GitHub Pages site, so this version uses no JSX imports or build tooling. The older `portfolio_website.jsx` file depends on React, Framer Motion, Tailwind utility classes, and project-specific UI components; it is not used by GitHub Pages unless a separate build workflow compiles it.
